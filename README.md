# VerifyAPI

A lightweight interface for the **Email Verification API** — a high-performance email validation tool that checks format, DNS/MX records, disposable domains, and more. The API is built with Express.js and TypeScript, and available on RapidAPI.

## Tech Stack
- **React 18** with TypeScript
- **Vite** for fast development and build
- **CSS Modules** for scoped styling

## Features
- Real-time email verification via API
- Displays validation results (valid/invalid) with reasons
- Rate limit status tracking
- Client-side email format validation
- Dark, responsive UI
